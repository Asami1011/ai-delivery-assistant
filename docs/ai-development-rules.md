# AI Development Rules

今後Codexが本プロジェクトで作業を行う際は、このドキュメントのルールを参照し、作業完了時の報告形式を統一する。

## 作業完了時

必ず以下を報告すること。

### 実施内容

何を実装したか。

### 変更ファイル

変更したファイル一覧。

### 追加ファイル

新規作成ファイル一覧。

### 削除ファイル

削除ファイル一覧。

### 設計判断

なぜその設計にしたか。

### 確認内容

実行したコマンド。

### 確認結果

以下の観点で結果を報告する。

- lint
- build
- test
- api

### リスク

懸念事項。

### 次の推奨タスク

WBS上の次タスク。
