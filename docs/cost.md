# Cost Strategy

## Cost Control Test Policy

現時点では、コスト制御に関する細かいテストはまだ実装していない。

MVP初期では、APIキー未設定時のデモモード、API契約、エラーハンドリングのFeature Testを優先する。

以下の機能を実装したタイミングで、コスト制御テストを追加する。

* 入力文字数制限
* 出力トークン上限
* モデル名の環境変数切り替え
* AIレビュア専用モデル
* デモモード強制設定
* レートリミット
* 利用量ログ
* 月間利用上限

追加予定のテスト:

* `AI_MAX_INPUT_LENGTH` を超える入力が拒否されること
* `AI_MAX_OUTPUT_TOKENS` がOpenAI APIリクエストに反映されること
* `OPENAI_MODEL_DEFAULT` が通常のAI機能で使われること
* `OPENAI_MODEL_REVIEW` がAIレビュアで使われること
* `AI_DEMO_MODE=true` の場合、OpenAI APIを呼び出さないこと
* `AI_RATE_LIMIT_PER_DAY` を超えたリクエストが制限されること

## 概要

本アプリは OpenAI API を利用するため、AI生成回数や入力文字数に応じてAPI利用料が発生する。

初期段階ではポートフォリオ用途・個人利用を想定し、低コストで運用できる設計にする。

## コストが発生する機能

* AI要件定義
* AIタスク分解
* AIレビュア
* AI業務改善提案

## コストが高くなりやすい機能

AIレビュア

理由:

* コード量が多い
* 差分が長くなる
* 設計資料も入力される可能性がある

## MVP運用方針

* APIキー未設定時はデモレスポンスを返す
* 入力文字数を制限する
* 出力サイズを制限する
* レビュー対象サイズを制限する
* 安価なモデルを利用する
* モデル名は環境変数から変更可能にする

## 将来的なコスト削減施策

* モデル切り替え
* キャッシュ
* 利用回数制限
* レートリミット
* 差分サイズ制限
* 入力要約
* 利用量ログ
* 月間利用上限
* 課金プラン別制御

## 環境変数

```env
OPENAI_API_KEY=
OPENAI_MODEL_DEFAULT=
OPENAI_MODEL_REVIEW=
AI_MAX_INPUT_LENGTH=
AI_MAX_OUTPUT_TOKENS=
AI_DEMO_MODE=
AI_RATE_LIMIT_PER_DAY=
```

## MVPで実装するもの

* APIキー未設定時のデモモード
* 入力文字数制限
* 出力トークン上限
* モデル名の環境変数化

## MVP後に実装するもの

* キャッシュ
* 利用量ログ
* モデル自動切り替え
* 月間利用制限
* 課金連携

## セキュリティ

* APIキーは絶対にコミットしない
* .env は git 管理しない
* .env.example のみ公開する
